# Executive Summary & Profitability Dashboard 📊✨

Welcome to my professional data analytics portfolio project! This repository contains a fully automated and interactive business intelligence dashboard built from scratch using Microsoft Excel, meticulously formatted for an **A4 Landscape layout**.

## 📌 Project Overview
This dashboard was engineered to track, analyze, and visualize corporate sales performance metrics across various global dimensions. It provides executives with real-time operational insights through synchronized charts and responsive controls.

## ⚙️ Core Features & Applied Techniques
* **Executive Performance Indicators (KPIs):** Instant aggregation of high-level business drivers, including *Total Revenue, Gross Profit, Units Sold, and Total COGS*.
* **Geographical Mapping Analytics:** Constructed a dynamic, interconnected Country-wise Live Map Chart using structured formulas as a bridge from underlying data models.
* **Granular Time-Series Visualization:** Trend profiling using custom Line and Column charts for monthly revenue cycles and structural cost tracking.
* **Dynamic Slicer Architecture:** Full background multi-chart synchronicity mapping using connected pivot filters for *Country, Sales Channel, Product Category, and Financial Quarters*.
* **Enterprise Asset Deliverable:** Successfully resolved data isolation limitations by sharing core data caches and formatting layout outputs for seamless executive PDF distribution.
